## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Styling

- KAMU HANYA BOLEH MENGGUNAKAN BADGE APABILA SANGAT DI PERLUKAN
- SETIAP SECTION HANYA BOLEH 1 JUDUL, ATAU DESC OPSIONAL. TAPI, SETIAP SECTION TIDAK BOLEH DI TUNJUKKAN TITLE NYA DALAM BENTUK BADGE, SAYA MAU DALAM BENTUK JUDUL SAJA
- KAMU HANYA BOLEH MENGGUNAKAN GRADIENT APABILA SANGAT DI PERLUKAN
- KAMU HANYA BOLEH MENGGUNAKAN NEON COLOR APABILA SANGAT DI PERLUKAN
- WAJIB LIGHT MODE
- BACKGROUND ELEMEN DAN WARNA TEKS HANYA BOLEH MONOKROM
- ICON ATAU BORDER SILAHKAN DI BERI WARNA TAPI OPSIONAL, TINGKAT KEWAJIBAN NYA 25%
- KURANGI EMOJI SEBANYAK MUNGKIN, KALAU BISA JANGAN PAKAI EMOJI TAPI PAKAI ICON
- JANGAN LUPA ANIMASI
- SIMPLE, MINIMALIST, TAPI MEWAH, TIDAK TERLALU RAMAI, TIDAK TERLALU PENUH, TIDAK TERLALU BESAR DAN SAYA MAU MUDAH DI FAHAMI
- PASANG ANIMASI SEBANYAK BANYAK NYA
